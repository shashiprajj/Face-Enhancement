Problem:
8,147 face-chip inputs were eligible; 754 were guard-blocked (9.3%). 751 were CHROMA_P99-only; 3 were multi-reason destructive outputs. R5-6 indicates roughly 650–700 may be legitimate deblurs. Destructive outputs were around chroma ≈120.

CALIBRATION DATA

Do NOT use archive TEST, ztest, 200 real photos, R5-6 test results, Feature-Match data, or future real-user data.

STEP 2 — FIND THE SAFETY SEPARATION
Test whether DEV supports a defensible distinction between normal deblur sharpening (roughly 10–16 chroma p99) and destructive artifacts (roughly 60–120+). Treat these as hypotheses, not assumptions.

Investigate:
- absolute chroma
- chroma increase
- relative increase
- high-frequency chroma
- high-frequency chroma relative to input
- high-frequency luma
- combined signals
- face validity
- grayscale preservation

Prefer a multi-signal guard over simply raising CHROMA_P99 10→20 if DEV evidence supports it.

STEP 3 — CHANGE ONLY IF DEV JUSTIFIES IT
If DEV shows a clear safety margin:
- make the smallest guard change that recovers legitimate deblurs
- preserve destructive-artifact protection
- version/seal the new configuration
- document evidence and exact change

If DEV does not support a defensible change:
- keep the guard unchanged
- document why
- continue with Objective 2

Never tune the guard using TEST/ztest/real-photo outcomes.
