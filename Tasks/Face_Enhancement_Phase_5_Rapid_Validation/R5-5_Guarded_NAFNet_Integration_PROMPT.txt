AUTHORITATIVE FINDINGS
The latest R5-ARCHIVE evaluation establishes:
- A4/SwinIR-L is the wrong model for blur: SFace Δ -0.014, dlib Δ -0.002, ~30.7 s/face.
- NAFNet-GoPro width-64 is the strongest deblurring candidate found so far: SFace Δ +0.162, dlib Δ +0.021, 44.3% clearly improved, 0% clearly harmed on the clean synthetic test sample, ~0.9 s/face CPU.
- NAFNet is NOT safe unconditionally: 14% artifacts on grainy ztest and 11/168 (6.5%) destroyed faces on the 200 real-photo check, especially pixelated/halftone/printed images.
- Therefore the required architecture is: dedicated strong-low-noise-blur input gate -> NAFNet -> output artifact guard -> ORIGINAL fallback.
- The archive Stage-1 "service path" recorded gate decisions but A4 invocation was a stub. This task must perform REAL NAFNet inference through the actual service.

ARTIFACT GUARD
Implement a dedicated structured artifact guard.

At minimum:
1. Output face validity check.
2. Lab chroma-change check. The archive evaluation used 99th-percentile Lab chroma distance and >10 as an evaluation artifact signal; make the threshold configurable rather than treating it as unquestionable production truth.
3. High-frequency color-energy check to catch rainbow/metallic streaks.
4. Numerical/output validity:
   - finite values
   - valid dimensions
   - valid dtype/range
   - no NaN/Inf
   - no channel corruption
5. Grayscale preservation:
   if input is grayscale/near-grayscale, do not allow strong invented color; otherwise fallback ORIGINAL.

Return a structured result, e.g.:
ArtifactGuardResult(
  passed=True/False,
  reasons=[...],
  metrics={...}
)

Possible reasons:
ARTIFACT_CHROMA_P99
ARTIFACT_HIGH_FREQ_COLOR
ARTIFACT_FACE_INVALID
ARTIFACT_NUMERIC_INVALID
ARTIFACT_GRAYSCALE_VIOLATION
