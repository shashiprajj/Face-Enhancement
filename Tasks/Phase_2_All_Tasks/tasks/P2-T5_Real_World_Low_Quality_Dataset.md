# P2-T5 — Real-World Low-Quality Face Test Set

## Objective
Address the Phase 1 gap around real-world blurry/low-quality face data.

## Work
1. Review the Phase 1 open issue and already-identified options.
2. Evaluate an internal consent-based dataset and approved external options such as Casual Conversations v2 or SCface, subject to license review.
3. Do not assume public availability means commercial permission.
4. Record source, license, intended use, restrictions and approval status.
5. If approved data cannot yet be acquired, create a concrete internal collection specification instead of fabricating data.
6. For internal collection, define capture conditions, consent/documentation, anonymized IDs, storage/retention and train/dev/test separation.
7. Do not collect unnecessary personal information.

## Deliverables
- `docs/phase_2/P2-T5_Real_World_Data_Plan.md`
- Source/license decision matrix.
- Acquisition manifest if approved data exists, otherwise an executable internal collection specification.

## Done When
There is a documented, legally reviewable path to real-world low-quality evaluation data.
