1. Read the Phase 0 and Phase 1 master specifications and final reports.
2. Inspect the actual project tree and existing dataset/model assets.
3. Inventory FairFace and every dataset asset actually acquired in Phase 1.

7. Record unresolved licensing, GPU and real-world-data issues.
8. Keep Feature-Match completely out of scope.

## Deliverables
- `docs/phase_2/P2-T1_Dataset_Inventory.md`
- Updated machine-readable inventory where useful.
