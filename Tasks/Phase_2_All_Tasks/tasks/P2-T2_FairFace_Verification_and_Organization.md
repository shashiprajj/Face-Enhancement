# P2-T2 — FairFace Verification & Organization

## Objective
Verify the FairFace dataset acquired in Phase 1 and organize a reproducible working copy without altering the raw source.

## Work
1. Verify completeness, readability, metadata and directory consistency.
2. Detect corrupt files and duplicates.
3. Verify checksums where available.
4. Determine which images are suitable for face-restoration benchmarking.
5. Separate immutable raw data from derived data.
6. Preserve source/sample/identity relationships supplied by the dataset.
7. Document license/source information using Phase 1 evidence.
8. Do not invent missing ground truth or silently change labels.

## Deliverables
- `docs/phase_2/P2-T2_FairFace_Verification.md`
- Dataset manifest and validation report.
- Reproducible organization/preparation script.

## Done When
The raw FairFace source is verified and a reproducible working representation exists.
