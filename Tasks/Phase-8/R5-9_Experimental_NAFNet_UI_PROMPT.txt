R5-9 — EXPERIMENTAL NAFNet UI + MANUAL EVALUATION HARNESS

OBJECTIVE
Expose the existing NAFNet research profiles through the current local FES UI so the owner can directly compare:
1. ORIGINAL
2. NAFNet R5-6 Reference
3. NAFNet R5-8 Experimental

This is a UI/integration task only. Do NOT change the enhancement algorithm, model weights, thresholds, gates, routing logic, or artifact detection.

CURRENT STATUS
- R5-6 is the historical reference profile.
- R5-8 is RED and must remain a research candidate only.
- NAFNet-GoPro width64 is the leading research model because it has shown the strongest identity-similarity benefit.
- Neither NAFNet profile is production-approved.
- Default/live behavior must remain unchanged.

============================================================
