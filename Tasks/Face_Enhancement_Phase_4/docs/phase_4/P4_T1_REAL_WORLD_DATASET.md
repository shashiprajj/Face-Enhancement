# P4-T1 — Real-World Dataset Acquisition & Governance

Objective: create a legally usable and representative real-world evaluation population.

Work:
1. Define intended production image conditions.
2. Identify candidate datasets/sources.
3. Record licence/permission.
4. Define identity/reference requirements.
5. Define dev/test separation.
6. Define leakage and near-duplicate checks.
7. Freeze manifest.
8. Validate image/metadata quality.
9. Produce dataset card.
10. Stop final evaluation if legal evidence is insufficient.

Required outputs: manifest, source/licence register, dataset card, leakage report, preparation configuration/scripts, SHA-256 hashes.
