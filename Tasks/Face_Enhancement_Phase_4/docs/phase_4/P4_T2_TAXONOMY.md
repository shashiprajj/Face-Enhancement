# P4-T2 — Real-World Degradation Taxonomy & Quality Metadata

Record where valid:
- image dimensions
- face dimensions
- blur/sharpness
- noise
- brightness/exposure
- contrast
- compression
- pose
- occlusion
- detector confidence
- alignment quality
- degradation family
- severity
- mixed-degradation flag

Observed real degradation must remain distinguishable from synthetic degradation. Threshold calibration uses development data only. Version all formulas, software and annotations.
