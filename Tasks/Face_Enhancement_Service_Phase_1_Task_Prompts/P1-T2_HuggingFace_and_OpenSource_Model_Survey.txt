PHASE 1 — TASK P1-T2
HUGGING FACE / OPEN-SOURCE MODEL SURVEY

PREREQUISITE
P1-T1 must be complete.

OBJECTIVE
Survey current face-enhancement, face-restoration, super-resolution, deblurring, and related model candidates that could satisfy the Phase 0 requirements.

IMPORTANT
This is a discovery task, NOT final model selection.

INSTRUCTIONS
1. Use current public sources and primary model repositories/model cards where available.
2. Search Hugging Face and relevant official repositories.
3. Identify model families relevant to:
   - face restoration
   - face super-resolution
   - deblurring
   - denoising
   - compression restoration
   - combined face restoration
4. Include established candidates where relevant, but do not assume any previously mentioned model is automatically suitable.
5. For every candidate record:
   - model/repository name
   - organization/author
   - task
   - architecture/family
   - model size if known
   - input/output expectations
   - supported degradation types
   - inference framework
   - GPU/CPU requirements
   - repository activity/maturity
   - documentation quality
   - code license
   - model-weight license
   - known restrictions
   - official source URLs
6. Distinguish verified facts from claims made by authors.
7. Do not download models in this task unless a tiny metadata-only operation is required.
8. Do not rank models as final winners.
9. Do not implement the service.
10. Do not inspect Feature-Match.

DELIVERABLE
Create:
docs/phase_1/P1-T2_Model_Survey.md

Create a machine-readable candidate inventory if useful:
docs/phase_1/model_candidates.csv

The report must identify:
- broad candidate pool
- candidates requiring immediate license rejection
- candidates needing deeper license verification
- technically promising candidates
- information gaps

ACCEPTANCE CRITERIA
- Candidate discovery is broad enough to avoid tunnel vision.
- Primary sources are recorded.
- License information is not guessed.
- Technical suitability is recorded separately from licensing eligibility.
- No final model winner is declared.

FINAL RESPONSE
Summarize the candidate pool and identify which candidates should move to P1-T3.
