PHASE 1 — TASK P1-T5
RESTORATION MODEL SHORTLIST & TEST DESIGN

PREREQUISITE
P1-T2 and P1-T3 must be complete. Review P1-T4 where preprocessing affects model compatibility.

OBJECTIVE
Produce a technically and legally defensible shortlist of enhancement/restoration candidates for benchmarking.

INSTRUCTIONS
1. Start only from candidates that are license-eligible or explicitly marked REVIEW_REQUIRED pending owner/reviewer approval.
2. Compare candidates against Phase 0 requirements:
   - low resolution
   - blur
   - noise
   - compression artifacts
   - lighting/contrast where applicable
   - identity preservation
   - deterministic behavior
   - CPU development feasibility
   - GPU production feasibility
   - memory requirements
   - output quality
3. Distinguish:
   - face-specific restoration
   - general image restoration
   - super-resolution
   - deblurring
   - multi-stage pipelines
4. Decide which candidates should actually be benchmarked.
5. Define why each shortlisted candidate is included.
6. Do not declare a final production model.
7. Define a standardized inference configuration for fair benchmarking.
8. Define what preprocessing/postprocessing must be held constant across candidates.
9. Do not implement the benchmark yet.

DELIVERABLE
Create:
docs/phase_1/P1-T5_Model_Shortlist_and_Test_Design.md

Include:
- shortlisted candidates
- exclusion reasons
- expected strengths/weaknesses
- benchmark configuration
- required preprocessing
- required hardware
- unresolved questions

ACCEPTANCE CRITERIA
- Shortlist is small enough to benchmark but broad enough to be meaningful.
- Every included candidate has a documented reason.
- License eligibility is visible.
- No final winner is declared.

FINAL RESPONSE
Report the shortlist and exact benchmark prerequisites.
