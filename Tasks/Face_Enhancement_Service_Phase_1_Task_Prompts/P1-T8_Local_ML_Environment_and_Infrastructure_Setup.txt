PHASE 1 — TASK P1-T8
LOCAL ML ENVIRONMENT & INFRASTRUCTURE SETUP

PREREQUISITE
P1-T1 through P1-T7 should be complete. Only install dependencies that are justified by the approved shortlist.

OBJECTIVE
Create a clean, reproducible development environment for model experimentation.

INSTRUCTIONS
1. Use a project-local Python environment.
2. Record Python version.
3. Install only dependencies needed for approved/eligible candidates and evaluation tooling.
4. Prefer pinned versions where practical.
5. Record CPU/GPU capability.
6. Detect whether NVIDIA CUDA is available.
7. If NVIDIA GPU is unavailable, do NOT fake GPU support and do NOT claim GPU benchmark readiness.
8. Prepare an optional GPU environment specification for the future benchmark machine.
9. Set up basic project directories for:
   - models
   - datasets
   - experiments
   - evaluation
   - reports
   - logs
10. Do not expose secrets/tokens in source control.
11. Do not implement production FastAPI.
12. Do not connect to Feature-Match.
13. Do not download unapproved models/datasets.

DELIVERABLE
Create:
docs/phase_1/P1-T8_Environment_Setup.md

Create/update:
requirements.txt or pyproject.toml/environment specification as appropriate.

Create:
docs/phase_1/ENVIRONMENT_MANIFEST.md

The manifest should record:
- Python
- OS
- CPU
- RAM
- GPU
- CUDA
- framework versions
- installed ML packages
- reproducibility notes

ACCEPTANCE CRITERIA
- Local environment is isolated from machine-wide packages.
- Versions are recorded.
- Environment can be reproduced.
- GPU limitations are explicit.
- No unapproved asset was downloaded.

FINAL RESPONSE
Report setup status and GPU readiness.
