PHASE 1 — TASK P1-T7
DATASET SELECTION & EVALUATION DATASET PLAN

PREREQUISITE
P1-T6 must be complete. Review P1-T4 and P1-T5.

OBJECTIVE
Create the final Phase 1 evaluation dataset plan without yet running model benchmarks.

INSTRUCTIONS
1. Select a practical evaluation portfolio from the eligible dataset candidates.
2. Ensure the plan covers:
   - low resolution
   - blur
   - noise
   - compression
   - mixed degradation
   - pose variation
   - lighting variation where available
   - different face sizes
   - same-identity quality comparisons
3. Include both:
   A. real-world degraded images where legally usable
   B. synthetic degradation of higher-quality reference images
4. Define synthetic degradation generation conceptually:
   - downsampling
   - blur kernels
   - motion blur
   - noise
   - JPEG compression
   - combined degradation
5. Define train/validation/test or benchmark-only splits.
6. Avoid identity leakage between evaluation subsets where relevant.
7. Define sample-size targets as TBD or justified estimates; do not invent final numbers.
8. Define dataset provenance tracking.
9. Do not train or benchmark models yet.

- selected datasets
- rationale
- license status
- evaluation subsets
- degradation matrix
- identity-preservation test design
- synthetic degradation plan
- split strategy
- provenance/versioning plan
- data-quality checks to perform after acquisition

ACCEPTANCE CRITERIA
- There is a concrete evaluation-data strategy.
- Same-identity/different-quality testing is possible.
- Real and synthetic degradation are both considered.
- Data provenance and licensing are traceable.
