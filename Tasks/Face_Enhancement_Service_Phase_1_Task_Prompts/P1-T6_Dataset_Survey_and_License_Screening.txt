PHASE 1 — TASK P1-T6
DATASET SURVEY & LICENSE SCREENING

PREREQUISITE
P1-T1 through P1-T5 should be complete.

OBJECTIVE
Find datasets suitable for evaluating face restoration under different image-quality conditions, with special attention to paired/same-identity quality variation.

CORE REQUIREMENT
The evaluation should include cases where the same person's face is represented at different quality levels, or where a high-quality reference can be degraded in a controlled and reproducible way.

INSTRUCTIONS
1. Search current public sources for relevant face-image datasets.
2. Consider:
   - paired high/low-quality datasets
   - face restoration datasets
   - face super-resolution datasets
   - deblurring datasets
   - general image restoration datasets with face subsets
   - high-quality face datasets that can be synthetically degraded
3. For each dataset record:
   - name
   - source
   - size
   - identity structure
   - image characteristics
   - paired/unpaired status
   - degradation types
   - metadata
   - train/validation/test split
   - license
   - commercial-use status
   - download/access method
   - known restrictions
4. Verify licenses from primary sources.
5. Clearly separate:
   - direct real-world low-quality data
   - paired ground truth data
   - synthetic degradation source data
6. Do not download datasets until license screening identifies them as eligible or explicitly approved for review.
7. Do not assume a dataset is commercially usable because its images are publicly downloadable.
8. Do not use private or sensitive data.

ACCEPTANCE CRITERIA
- Dataset candidates cover the needed evaluation scenarios.
- Same-identity/different-quality testing is explicitly addressed.
- Licensing is documented.
- Synthetic-degradation datasets are considered as a fallback/companion strategy.
- No unlicensed dataset is downloaded.

FINAL RESPONSE
Summarize dataset candidates and identify which can proceed to selection.
