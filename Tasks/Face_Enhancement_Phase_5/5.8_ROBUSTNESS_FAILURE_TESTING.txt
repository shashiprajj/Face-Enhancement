TASK 5.8 — ROBUSTNESS AND FAILURE TESTING

Objective: prove the service fails safely instead of producing confident-looking unsafe output.

Test: good images, blur, noise, tiny faces, dark/overexposed, JPEG artifacts, mixed degradation, no face, multiple faces, partial face, extreme pose, rotation, corrupt/truncated files, oversized files, unusual formats/aspect ratios, repeated requests, bounded concurrency, model exception and timeout/hung inference.

Do:
1. Build deterministic robustness corpus.
2. Define expected behavior for each class.
3. Run repeated tests.
4. Verify original fallback whenever enhancement is unsafe/unavailable.
5. Verify no crash leaks or undefined route states.
6. Measure sequential/bounded concurrent CPU resource behavior.
7. Verify timeout/process-isolation behavior if implemented.
8. Run regression suite.
9. Record/classify/fix failures in scope and rerun.

Acceptance: no critical unsafe failure; every input gets validated enhancement or safe fallback.
