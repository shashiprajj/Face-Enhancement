# Face Enhancement Service — Phase 5
Real-World Enhancement + Feature-Match Validation

Objective: build and validate a genuinely useful face-enhancement pipeline for poor-quality real images, using CPU-only execution, with the actual Feature-Match system as the decisive evaluation.

Baseline: Phase 4 complete, YELLOW. T6 Do-Not-Enhance and T7 selective routing frozen. A4 is the only current enhancement candidate. A1/A2/A5 must not be routed. Synthetic evidence is promising but insufficient. CPU-only is acceptable; licensing remains a production-approval track.

Tasks: 5.1 baseline freeze; 5.2 real-world dataset; 5.3 production-like detection/alignment; 5.4 standalone CPU A4 service; 5.5 actual Feature-Match evaluation; 5.6 real-world gate/router calibration; 5.7 human identity/fabrication review; 5.8 robustness/failure testing; 5.9 final evidence gate.

Execution: complete each task, report results, run validation/tests, commit intended changes, and stop at the task gate. Do not silently expand scope.
